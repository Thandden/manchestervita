# Manchester Vita static website

Static HTML/CSS website for Manchester cosmetic-procedure enquiries.

## Deploy

Upload the repository root to Netlify, Cloudflare Pages, GitHub Pages or any static host. The enquiry form includes Netlify Forms attributes; on another host, replace the form `action` with that host's form endpoint.

## Before launch

1. Confirm ownership of `manchestervita.co.uk`; replace canonical and sitemap URLs if the final domain differs.
2. Replace the placeholder postal address if needed and never describe it as a treatment location unless patients can attend it.
3. Add the legal operator/company details to the privacy and terms pages.
4. Test form delivery and phone links.
5. Have medical content and advertising claims reviewed by an appropriately qualified UK professional.
6. Add only licensed, consented photography. The current design intentionally works without stock imagery.
